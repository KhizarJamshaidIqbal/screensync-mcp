Install in two minutes.

  1. 1

    Run the hub on your computer

    In the repo: cd mcp-server && npm install && npm run build && npm start. A pairing QR prints.

  2. 2

    Load the extension

    Chrome → chrome://extensions → Developer mode → Load unpacked → select the extension/ folder (or unzip the release package).

  3. 3

    Pair & go live

    The wizard probes localhost, or paste the pairing link from the hub's QR. Done — your phone streams into the dashboard tab.

What the extension asks for

  • localhost only, by default. LAN origins are requested at runtime, only for the address you enter.
  • No accounts, no analytics. Settings (hub URL + token) live in your browser's local extension storage.
  • Same security model as the app: bearer token over your LAN, MediaProjection consent on the phone for every capture session.

Requirements

Chrome / Edge 110+ · a computer running the ScreenSync hub · the Android app on your phone for captures (control tools work over ADB).
